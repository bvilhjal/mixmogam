# Critical review, 3 October 2026

mixmogam has a useful computational core: blockwise association scans,
operator-based kinships, and shared LOCO solves. The pre-review package also
contained serious errors that its passing tests did not detect. This cleanup
corrects the reproduced defects and adds independent checks. It does **not**
establish calibrated inference across populations or equivalence to BOLT-LMM
or LDAK-KVIK. Keep the package at development status until that evidence exists.

The review began with a clean checkout at
`2b8d6b71ade001e94dae74382297915eb0d653c9` on
`bolt-kvik-structure-calibration`. Changes are identified as `2.0.0.dev1`.
Historical benchmark sources, data, figures, and PDFs are preserved.

## Reproduced defects and corrections

Table 1. Findings, ordered by consequence. P1 means an incorrect scientific
result or corrupted input; P2 means an important contract or efficiency defect.

| Priority | Pre-review failure | Correction and independent check |
|---|---|---|
| P1 | BED reader and writer shared the same wrong encoding, so their round-trip test passed. Byte `0xe4` decoded as `[0, 1, 2, -1]`. | The specification requires counted-A1 calls `[2, -1, 1, 0]`. A hand-written fixture now checks both directions; BIM alleles and distinct chromosome labels survive IO. Standard TPED allele pairs are supported. |
| P1 | BLUP multiplied by genetic variance twice. In the seeded example, multiplying the phenotype by three multiplied the prediction by 27. Operator predictions omitted the genetic component. | Compare the prediction with the Gaussian conditional mean from a direct covariance solve and check linear scaling; use CG for operator and truncated-spectrum predictions. |
| P1 | The purported Bayes factor was an unpenalized likelihood ratio, then normalized across SNPs. The strongest SNP's posterior could never exceed its prior. | Require beta, standard error, and an explicit normal effect-prior variance; compare with the ratio of integrated normal densities. Subsetting SNPs no longer changes their posterior odds. |
| P1 | Default permutations shuffled correlated fitted residual entries and projected them again. Covariates destroy their exchangeability. | Rotate into the orthonormal residual subspace, permute coordinates, and rotate back using Householder reflectors. Check against a separately constructed full complement on a small example. |
| P1 | Missing aligned samples inherited the first sample's calls; duplicate phenotype observations silently overwrote one another. RegMap files were joined on the wrong axis. | Missing rows contain only missing calls; duplicates require explicit handling; multi-file loading aligns sample headers and stacks variants. |
| P1 | Diploid MAC counted nonreference carriers rather than allele copies. Fractional, out-of-range, and nonfinite calls could be silently cast. | Count actual allele copies, validate before conversion, distinguish counted-allele frequency from MAF, and explicitly recode inbred benchmark calls to 0/2. |
| P1 | ML used the REML variance divisor, changes in fit options could reuse a stale fit, and a large intercept could invalidate the likelihood. | Check ML against a direct quadratic divided by n; key the cache by fit options; evaluate residual quadratics without subtracting large squares. Reject fully explained phenotypes and operations on superseded fits. |
| P1 | Streaming kinships ignored weights. Window complements double-counted overlapping windows or missed gaps. | Compare weighted operators with dense weighted GRMs, including streaming mode; compare every window complement with the direct complement GRM. |
| P2 | CSV discarded identifiers/effects/precision; optional dependencies hid unrelated IO tests; source distributions omitted test helpers. | Preserve variant fields and quoted IDs, scope optional skips to the relevant tests, package the complete test sources, and exercise a core-only dependency environment. |
| P2 | LOCO products retained a matrix for every group and right-hand side. Several edge paths silently ignored options or accepted incomplete solves. | Accumulate total and own-group products only; enforce CG convergence, expose variational convergence, handle small spectral scans, and reject unused options. |

The BLUP identity underlying the correction is Equation 1, with
`delta = ve / vg` and residual `r = y - X beta`:

\[
\widehat u = v_g K(v_gK+v_eI)^{-1}r
            = K(K+\delta I)^{-1}r. \tag{1}
\]

The file-format check follows the [official PLINK BED specification](https://www.cog-genomics.org/plink/1.9/formats#bed).
The permutation construction follows [Abney's residual-coordinate argument](https://home.uchicago.edu/~abney/abney_web/Publications_files/abney2015a.pdf):
exchangeability holds under a Gaussian null with known covariance. Estimated
variance components make the implemented test a plug-in procedure.
The posterior uses the normal approximation underlying
[Wakefield's approximate Bayes factor](https://pubmed.ncbi.nlm.nih.gov/18642345/),
not a joint fine-mapping model.

## What remains unvalidated

The external comparison in `20261003T083746Z-kvik-reference` used the broken
BED writer. Inbred 0/2 calls became homozygotes/heterozygotes in the external
program, changing allele frequencies and frequency-dependent weights. Some
standardized quantities can survive a linear recoding, but this does not make
the inputs equivalent. The reported external concordance and relative timings
must be rerun before citation. The updated harness verifies exported calls,
uses corrected MAC and missingness, and reports finite tested counts. No
external-program rerun was performed during this cleanup.

The existing PDFs predate these changes. Their historical projected-residual
permutation thresholds do not validate the corrected default. Original
in-package timing comparisons remain historical measurements against the
legacy-style loop, not evidence of superiority to independent programs.

Table 2. Recommended next work, in priority order.

| Priority | Improvement | Evidence required |
|---|---|---|
| 1 | Rebuild the external comparison and null-calibration benchmark. | Identical samples, alleles, genotypes, QC, covariates, and phenotype scales; archived tool versions and inputs; independent seeded null replicates with rejection rates and uncertainty by MAC, LD, missingness, and structure. Report failures and tested denominators. |
| 2 | Audit the spectral correction with held-out calibration SNPs. | The same small SNP panel currently selects the spectral width and measures its fit. A small calibration CV is not independent validation. Check held-out denominators and tail error rates; treat transfer to mixture/elastic-net statistics as heuristic. |
| 3 | Keep internal CV distinct from prediction validation. | BOLT/KVIK tuning uses cohort-wide preprocessing and variance fitting. Its internal CV scores are useful tuning diagnostics, not independent accuracy estimates. Any prediction claim needs training-only preprocessing and a genuinely held-out outcome. |
| 4 | Extend boundaries and memory controls before population-scale claims. | Add tests for custom operators, near-singular designs, and poorly identified two-kinship mixtures. Measure runtime and process RSS across cohort sizes; budget per-group spectral bases. The expanded hard-call store is not packed BED, and fractional dosages remain unsupported. |

The default exact path computes the matrix algebra exactly but still uses an
EMMAX plug-in F test. Kinship adjustment does not guarantee removal of
environmental confounding. Binary-trait imbalance requires validation or a
different likelihood; a Gaussian quantitative-trait interface should not imply
otherwise. Results from this implementation's constant-denominator paths also
do not establish a general claim about every REGENIE or SAIGE analysis mode.

Matched external results and replicated, independent null calibration would
justify strengthening the package's claims. Passing unit tests alone would not.

## Validation and efficiency

Regression cases are in [test_review_regressions.py](../tests/test_review_regressions.py).
The original fast suite passed all 73 tests before the defects were fixed.
The new tests use specification fixtures, direct linear algebra, integrated
densities, and explicit small-matrix constructions rather than only round trips.
Current test and distribution results are recorded in
[validation.json](../benchmarks/results/20261003-critical-review/validation.json).

The [LOCO allocation record](../benchmarks/results/20261003-critical-review/loco_memory.json)
compares the baseline with the corrected implementation at n=800, m=1,000,
10 groups and 80 right-hand sides, float64, seed 313, blocks of 100. Temporary
tracked allocation fell from about 6.90 to 2.50 MiB (64%); results were identical.
Five warm repeats do not establish a runtime improvement. This measurement
excludes the existing genotype cache and native BLAS allocations, so it is not
whole-process peak RSS. Reproduce it on AC power with Low Power Mode disabled:

```sh
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1 \
  python benchmarks/review_memory.py --output /tmp/loco_memory.json
```

Compatibility changes and examples are in the
[quickstart contracts](quickstart.md#input-and-inference-contracts) and
[changelog](../CHANGELOG.md). Existing incorrectly written BED files must be
regenerated from the source calls; the corrected decoder cannot infer their
intended encoding.
